# Analytics Architecture Guide

## 🧠 The "Global Analytics" Philosophy

This folder structure is designed to give you the best of both worlds: **Speed** (Obsidian Native) and **Power** (Python/AI).

### 1. When to use Native Tools (`01_Native_Tools`)
Use **Dataview** or **Canvas** when you need:
- **Live Updates**: Data changes instantly as you type.
- **Navigation**: Clickable links to files in your vault.
- **Simple Aggregation**: Lists of files, basic tables, task lists.
- **Visual Context**: Seeing notes on a canvas.

*Example:* "Show me all files modified today" or "List all tasks tagged #research."

### 2. When to use Python Engine (`02_Python_Engine`)
Use **Python** scripts when you need:
- **Deep Content Analysis**: Reading the *text* of 1000 files to find semantic similarities.
- **External Data**: Fetching citations from ArXiv, Wikipedia, or Semantic Scholar.
- **Complex Math**: Calculating coherence scores, running simulations, or heavy statistics.
- **AI Integration**: Sending text to GPT/Claude for summary or critique.
- **Static Reports**: Generating a fixed "Weekly Report" that doesn't change every time you open it.

*Example:* "Analyze the sentiment of all my journal entries from 2024" or "Generate a knowledge graph of all physics terms."

---

## 📂 Folder Structure

- **`01_Native_Tools/`**:
  - Ready-to-use Dataview dashboards.
  - Copy these to any folder to get instant local analytics.
- **`02_Python_Engine/`**:
  - `Scripts/`: The heavy machinery (Python files).
  - `Output_Data/`: Where raw data (JSON/CSV) is saved.
  - `Reports/`: Human-readable reports generated by the engine.
- **`03_Dashboards/`**:
  - High-level control centers that might combine Dataview queries with links to Python reports.
- **`04_Custom_Modules/`**:
  - Specialized tools for specific domains (e.g., Theophysics, Atoms).
  - **Your "Secret Sauce" goes here.**

## 🚀 How to Deploy
Use the **Template Engine** to copy this structure into any new project:
1. Run the `replicate_analytics` command (via Python script).
2. It creates a `Local_Analytics` folder in your project.
3. You get all these tools, scoped to that specific project folder.
