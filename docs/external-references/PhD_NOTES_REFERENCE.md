Source: https://github.com/Regularman/PhD-notes . Local supplied download: \\192.168.2.50\h_hp\Downloads\Compressed\PhD-notes-main .

This is an academic energy-research vault, not a software plugin. The supplied folder contains 543 files, including 170 Markdown notes and two Canvas files; much of its roughly 112 MB is imagery. Keep the original external vault in place as a reference. It is not imported wholesale into the application repository, installed or made authoritative over David's work. No license file was found in the supplied root/tree; original prose and images are not bundled here.

Useful patterns inspected:
- Literature notes separate a paper's contribution, methods/content, limitations, questions and further reading.
- The research-question matrix connects questions, context, methodology and candidate sources.
- Literature Canvas arranges linked papers/notes visually; its edges do not by themselves establish evidential relationships.
- Project planning separates scope, scenarios, open ideas and comparisons.

Adapted original templates live in templates/research-workflows. They add source/version lineage, how/why questions, explicit verification methods, distinct contribution, objections and review receipts needed for this project. These are workflow candidates, not a change to the agreed canonical schema.

For Codex: use this reference to improve dossier/question/review interfaces, not as a code dependency. Do not bulk-copy another researcher's notes, imagery or personal workspace settings into David's vault. Do not clone the whole vault to satisfy a dependency install; there is no runtime dependency.
