# Review-call contract

One envelope supports focused claims, foundations, derivations, alternatives, failure_boundaries, contribution and canon_assessment tasks. Local integrity checks feed observations into it. Task types are not extra folders.

Requests include exact targets/editions, permitted source passages, actual applicable rule text with IDs/versions, authoritative ruling references, checker-versioned local observations, coverage/errors, missing context and privacy scope. One-hop context is a size heuristic, not permission to omit load-bearing material. Missing necessary context returns cannot_assess. Keep requests bounded; do not resend the corpus.

The host computes task IDs and bundle hashes; it records actual timing, provider usage and cost. Models return source-located findings, limitations, missing inputs and a recommendation only. They cannot set canon, identities, authorizations, measured facts or approvals. Checker observations are not infallible premises: reviewers may flag stale bindings or inconsistent measurements.

Reject truncated, malformed, out-of-scope or unexpected-field responses as incomplete. Cache keys include all effective inputs, rules/rulings, prompt/model configuration and tool/context versions. No silent reuse across changed evidence.

Phase 1 only writes dry requests. Later provider calls require explicitly allowed provider/model, total/per-call budget, accounting, idempotency and retries within the SAME total cap. No credentials in the repository.
